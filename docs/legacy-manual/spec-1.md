## ความเสี่ยง › ERM1 (หน้า 2–5, p04–p07)

**วัตถุประสงค์:** วิเคราะห์สภาพแวดล้อมองค์กร / บริบทเกี่ยวกับหน่วยงาน (Organization Context)
หัวหน้าเป็น "ERM1 : วิเคราะห์สภาพแวดล้อมองค์กร / บริบทเกี่ยวกับหน่วยงาน (Organization Context)"

**ผู้ใช้:** คู่มือไม่ได้ระบุ

### โครงสร้างหน้า (หน้า 2)
- แถวบนมี "ปีงบประมาณ" (dropdown), "คณะ / หน่วยงาน" (dropdown), ปุ่ม "ค้นหา" และปุ่ม "+ เพิ่มวัตถุประสงค์เชิงกลยุทธ์"
- ตารางหลักมีหัวคอลัมน์ "รหัส" | "วัตถุประสงค์เชิงกลยุทธ์" | ไอคอนแก้ไข (ดินสอ) และลบ (ถังขยะ)
  - ถ้ายังไม่มีข้อมูลจะแสดง "-- No Data --"
  - ตัวอย่างแถว: "S01 จัดการศึกษาสอดคล้องกับความต้องการของสากล", "S05 ปฏิรูปการบริหารจัดการ (Management Reform)"
- ตารางเป็นแบบซ้อนกัน 3 ชั้น ขยาย/ยุบได้ด้วยปุ่ม + / − หน้ารหัส
  1. ชั้นวัตถุประสงค์เชิงกลยุทธ์
     - เมื่อขยายจะมีหัวว่า "วัตถุประสงค์เชิงกลยุทธ์ : S01 …" พร้อมปุ่ม "+ เพิ่มเป้าประสงค์"
     - ตารางย่อยมีคอลัมน์ "รหัส" | "เป้าประสงค์" | แก้ไข/ลบ
  2. ชั้นเป้าประสงค์
     - เมื่อขยายจะมีหัวว่า "วัตถุประสงค์ 1 พัฒนาระบบบริหารงานบุคคลให้มีประสิทธิภาพ" พร้อมปุ่ม "+ กระบวนการดำเนินงาน(หลัก)"
     - คู่มือใช้คำว่า "วัตถุประสงค์" ในหัวนี้ แม้จะเป็นระดับเป้าประสงค์
  3. ชั้นกระบวนการดำเนินงาน
     - คอลัมน์: "#" | "กระบวนการดำเนินงาน(หลัก)" | "บันทึกการวิเคราะห์สภาพแวดล้อม" (ปุ่ม "บันทึก") | "รายงานการวิเคราะห์สภาพแวดล้อม" (ปุ่ม "รายงาน") | แก้ไข/ลบ

### ขั้นตอนที่ 1: กรอกข้อมูลวัตถุประสงค์เชิงกลยุทธ์ (หน้า 2)
1. เข้าเมนู ERM1 แล้วเลือก "ปีงบประมาณ" และ "คณะ/หน่วยงาน"
2. กดปุ่ม "+เพิ่มวัตถุประสงค์เชิงกลยุทธ์" ระบบเปิด dialog "เพิ่ม : วัตถุประสงค์เชิงกลยุทธ์" (มีปุ่ม × ปิด)
   - "รหัส": text ตัวอย่าง "S01"
   - "ชื่อ": text placeholder "วัตถุประสงค์เชิงกลยุทธ์"
   - ปุ่ม "บันทึก" (สีน้ำเงิน) และ "ยกเลิก" (สีส้มแดง)
   - คู่มือไม่ได้ระบุว่าฟิลด์ไหนบังคับกรอก
3. บันทึกแล้วรายการใหม่จะขึ้นในตาราง

### ขั้นตอนที่ 2: กรอกข้อมูลเป้าประสงค์ (หน้า 3)
1. กด "+" หน้ารหัสวัตถุประสงค์เชิงกลยุทธ์ แล้วกดปุ่ม "+เพิ่มเป้าประสงค์"
2. ระบบเปิด dialog "เพิ่ม : เป้าประสงค์ที่"
   - "เป้าประสงค์ที่": text/number ตัวอย่าง "1"
   - "ชื่อเป้าประสงค์": text placeholder "เป้าประสงค์ที่"
   - ปุ่ม "บันทึก" และ "ยกเลิก"
3. บันทึกแล้วรายการใหม่จะขึ้นในตาราง

### ขั้นตอนที่ 3: กระบวนการดำเนินงาน(หลัก) (หน้า 3)
1. กด "+" หน้ารหัสเป้าประสงค์ แล้วกดปุ่ม "+กระบวนการดำเนินงาน(หลัก)"
2. ระบบเปิด dialog "เพิ่ม : กระบวนการดำเนินงาน(หลัก)"
   - ฟิลด์เดียว "กระบวนการดำเนินงาน(หลัก)" (text)
   - ปุ่ม "บันทึก" และ "ยกเลิก"

### ขั้นตอนที่ 4: บันทึกข้อมูล ERM1 : วิเคราะห์สภาพแวดล้อมองค์กร (หน้า 4–5)
กดปุ่ม "บันทึก" ในแถวของกระบวนการดำเนินงานที่ต้องการ ระบบเปิดหน้าจอแบบ stepper 5 ขั้น
ทุกขั้นที่มีฟอร์มจะมีปุ่ม "บันทึก" และไปขั้นถัดไปด้วยปุ่ม "Next >"

1. **"External Environment (PESTEL)"**
   - หัวข้อ "วิเคราะห์ External Environment (PESTEL)"
   - dropdown placeholder "เลือก PESTEL" (ไม่เห็นรายการตัวเลือก ในตารางสรุปมีค่า "Social" จึงน่าจะเป็นหมวด P/E/S/T/E/L)
   - rich-text editor (undo/redo, B, I, U, S, จัดชิดซ้าย/กลาง/ขวา/เต็มแนว) placeholder "วิเคราะห์ External Environment (PESTEL)..."
   - ปุ่ม "บันทึก"
2. **"Internal Environment (McKinsey 7S model)"**
   - หัวข้อ "วิเคราะห์ Internal Environment (McKinsey 7S model)"
   - dropdown "เลือก McKinsey 7S model" (ในตารางสรุปมีค่า "Structure")
   - rich-text editor และปุ่ม "บันทึก"
   - ข้อสังเกต: ใน PESTEL และ 7S น่าจะเลือกหมวดใน dropdown แล้วเขียนข้อความแยกทีละหมวด เพราะตารางสรุปแสดงหลายหัวข้อ เช่น S1, S2 ใต้ "Social"
3. **"Situation Analysis"**
   - หัวข้อ "Situation Analysis วิเคราะห์แนวโน้มการเปลี่ยนแปลง (Mega Trend/PESTEL) & 7S"
   - rich-text editor (ไม่มี dropdown) และปุ่ม "บันทึก"
4. **"Key Risks & SOFC"**
   - หัวข้อ "ระบุเหตุการณ์ความเสี่ยง (Key Risks) และ ระบุประเภทความเสี่ยง (SOFC)"
   - "ระบุเหตุการณ์ความเสี่ยง (Key Risks)": text ตัวอย่าง "การผลิตบัณฑิตให้ทันต่อการเปลี่ยนแปลงของสถานการณ์ปัจจุบัน"
   - "ระบุประเภทความเสี่ยง (SOFC)": dropdown มีปุ่ม × ล้างค่า
     - ค่าที่เห็นในภาพ: "ความเสี่ยงด้านการปฏิบัติงาน (Operation Risks)"
     - ในตารางสรุปเห็น "ความเสี่ยงด้านกลยุทธ์ (Strategic Risks)"
     - ตัวเลือก F/C ไม่เห็นในภาพ แต่ตามหลัก SOFC น่าจะเป็นด้านการเงิน (Financial) และด้านการปฏิบัติตามกฎระเบียบ (Compliance) ข้อนี้เป็นการอนุมาน ไม่ชัด
   - ปุ่ม "บันทึก"
5. **"รายงาน ERM1"**
   - หัวข้อ "แบบฟอร์มการวิเคราะห์สภาพแวดล้อมองค์กร/ บริบทเกี่ยวกับหน่วยงาน (Organization Context)"
   - ตารางสรุป 5 คอลัมน์:
     1. "วิเคราะห์ External Environment (PESTEL)"
     2. "วิเคราะห์ Internal Environment (McKinsey 7S model)"
     3. "Situation Analysis วิเคราะห์แนวโน้มการเปลี่ยนแปลง (Mega Trend/PESTEL) & 7S"
     4. "ระบุเหตุการณ์ความเสี่ยง (Key Risks*)"
     5. "ระบุประเภทความเสี่ยง (SOFC)"
   - ตัวอย่างข้อมูลในเซลล์:
     - PESTEL: "Social" แล้วตามด้วย "S1 : การจัดการเรียนการสอนแนวใหม่/การเปลี่ยนแปลงทางสังคมอย่างรวดเร็ว…" และ "S2 : การจัดการ…"
     - 7S: "Structure" แล้วตามด้วยข้อความ
     - Situation Analysis: รายการลำดับ 1), 2)
     - Key Risks: "Key Risks (1)" แล้วตามด้วยข้อความ
     - SOFC: "ประเภทความเสี่ยง (SOFC)" แล้วตามด้วย "ความเสี่ยงด้านกลยุทธ์ (Strategic Risks)(การจัดการศึกษา/วิจัย/บริการ" (ข้อความถูกตัด ไม่ชัด)

### ปุ่ม "รายงาน" ในแถวกระบวนการ
- น่าจะเปิดรายงาน ERM1 (ขั้นที่ 5) แต่คู่มือไม่ได้อธิบาย ไม่ชัด

### ความเชื่อมโยงกับเมนูอื่น
- "Key Risks" ที่บันทึกใน ERM1 จะกลายเป็นรายการ "ความเสี่ยงที่ N" ในหน้า ERM2 - 3
- โครงสร้างข้อมูลเป็นลำดับชั้น: ปีงบประมาณ + หน่วยงาน → วัตถุประสงค์เชิงกลยุทธ์ → เป้าประสงค์ → กระบวนการดำเนินงาน(หลัก) → ERM1 (PESTEL/7S/Situation/Key Risks+SOFC)

## ความเสี่ยง › ERM2 - 3: ส่วน ERM2 (หน้า 6–8, p08–p10; หน้า 9 อยู่นอกช่วงของ spec นี้)

**วัตถุประสงค์:** ระบุปัจจัยเสี่ยง, การควบคุมที่มีอยู่ และประเมินระดับความเสี่ยงของแต่ละความเสี่ยงจาก ERM1

**ผู้ใช้:** คู่มือไม่ได้ระบุ

### ขั้นตอนที่ 1: ค้นหาข้อมูลความเสี่ยงที่บันทึกใน ERM1 (หน้า 6)
1. เข้าเมนู "ERM2-3" (หัวหน้าเขียนว่า "ERM2 - 3")
2. เลือก "ปีงบประมาณ" และ "คณะ / หน่วยงาน" แล้วกด "ค้นหา"
3. ระบบแสดงรายการเป็นแบบ tree/กลุ่ม
   - แถบหัวเขียนว่า "วัตถุประสงค์เชิงกลยุทธ์ / เป้าประสงค์ / กระบวนการดำเนินงาน(หลัก) / เหตุการณ์ความเสี่ยง (Key Risks*)"
   - แถว "วัตถุประสงค์เชิงกลยุทธ์ : S01 …" (พื้นฟ้าอ่อน)
   - ใต้นั้นเป็น "เป้าประสงค์ที่ 1 …"
   - ใต้นั้นเป็น "กระบวนการดำเนินงานที่ 1 …"
   - ใต้นั้นเป็น "ความเสี่ยงที่ 1 : วิเคราะห์สภาพแวดล้อมที่มีผลกระทบต่อเป้าหมายขององค์กร" ซึ่งเป็นลิงก์ขีดเส้นใต้

### ขั้นตอนที่ 2: กรอกข้อมูล ERM2 ตามหัวข้อที่กำหนด (หน้า 6–8)

#### 1) สาเหตุความเสี่ยง/ปัจจัยเสี่ยง (หน้า 6)
- ฟิลด์ "สาเหตุความเสี่ยง/ปัจจัยเสี่ยง": text placeholder "ระบุเหตุการณ์ความเสี่ยง (Key Risks)"

- ใต้ปุ่มมีลิงก์ขีดเส้นใต้ "สาเหตุความเสี่ยง/ปัจจัยเสี่ยง" ซึ่งน่าจะเป็นรายการปัจจัยที่บันทึกแล้ว (ไม่ชัด)

#### 2) การควบคุมที่มีอยู่ / กลยุทธ์ที่ใช้ควบคุม Existing Controls (หน้า 7)
- แถว Tab: Tab แรก "Existing Controls" (ภาพรวม) ตามด้วย Tab ละหนึ่งปัจจัยเสี่ยง
- **Tab "Existing Controls":** ตาราง 4 คอลัมน์

  2. "1. Existing Preventive Controls (ควบคุมก่อนเกิดเหตุ)"
  3. "2. Existing Loss Controls (ควบคุมหลังเกิดเหตุ/ลดผลกระทบ)"
  4. "3. การควบคุมที่มีอยู่"
- **Tab ของปัจจัยเสี่ยง:**
  - dropdown "เลือก Existing Controls" (ตัวเลือกไม่เห็น น่าจะเป็น Preventive / Loss ไม่ชัด)
  - rich-text editor placeholder "วิเคราะห์ Existing Controls..."
  - ปุ่ม "บันทึก"
  - radio "การควบคุมที่มีอยู่" มี 2 ตัวเลือก: "เพียงพอ" / "ไม่เพียงพอ"
  - ใต้ radio แสดงข้อความที่บันทึกไว้ ใต้หัว "1.Existing Preventive Controls (ควบคุมก่อนเกิดเหตุ) :" และ "2.Existing Loss Controls (ควบคุมหลังเกิดเหตุ/ลดผลกระทบ) :"
  - วิธีใช้: เลือกประเภทการควบคุม กรอกข้อมูล กด "บันทึก" แล้วกด "Next >"

#### 3) ผลการประเมินระดับความเสี่ยง จากการควบคุมที่ใช้อยู่ (ระดับความเสี่ยง ณ เริ่มต้น) (หน้า 8)
- Tab แรก "ระดับความเสี่ยง ณ เริ่มต้น" (ภาพรวม) ตามด้วย Tab ละหนึ่งปัจจัยเสี่ยง
- **Tab ภาพรวม:** ตาราง 4 คอลัมน์
  1. "ปัจจัยเสี่ยง"
  2. "โอกาสที่จะเกิดเหตุการณ์ที่เป็นความเสี่ยง (L)" (ค่าตั้งต้นแสดง "L = 0 =")
  3. "ความรุนแรงของผลกระทบต่อองค์กร ( I/C )" (ค่าตั้งต้นแสดง "I = 0 =")
  4. "ระดับความเสี่ยง" (risk matrix 5×5)
- **Tab ของปัจจัยเสี่ยง:**
  - กลุ่ม "โอกาสที่จะเกิดเหตุการณ์ที่เป็นความเสี่ยง (L)" มี dropdown 2 ตัวซ้อนกัน
    - ตัวแรก label ประมาณ "เลือก ประเด็น/องค์ประกอบที่พิจารณาเรื่องการที่จะเกิดความเสี่ยง (L)" (ไม่ชัด) ตัวอย่างค่า "ความถี่จะเกิดข้อผิดพลาดในการปฏิบัติงาน (เฉลี่ย : ปี/ครั้ง)"
    - ตัวที่สอง label ประมาณ "เลือก ความถี่ / ความเป็นไปได้ของโอกาสที่จะเกิดความเสี่ยง" (ไม่ชัด) ตัวอย่างค่า "1 เดือนต่อครั้งหรือมากกว่าต่อเดือน"
    - เลือกแล้วกล่องผลด้านขวาแสดง "5|สูงมาก" (ตัวแดง กรอบประแดง)
  - กลุ่ม "ความรุนแรงของผลกระทบต่อองค์กร ( I/C )" มี dropdown 2 ตัว
    - ตัวแรก "เลือก ความเสียหาย/ผลกระทบต่อองค์กร (I/C)" (ไม่ชัด) ตัวอย่างค่า "หยุดให้บริการ"
    - ตัวที่สอง "เลือก มูลค่าที่เสียหาย" (ไม่ชัด) ตัวอย่างค่า "½ - 1 วัน"
    - เลือกแล้วกล่องผลแสดง "2|น้อย" (ตัวเขียว กรอบประเขียว)
  - ปุ่ม "บันทึก"
  - ด้านขวามีหัว "Residual Risk Level"
    - ใช้หัวนี้แม้จะอยู่ในขั้น "ณ เริ่มต้น"
    - แสดง matrix ที่ไฮไลต์ช่องผลลัพธ์ ตัวอย่างช่อง 10 สีส้ม
    - ใต้ matrix มีคำอธิบาย:
      - "(ระดับความเสี่ยง เริ่มต้น) = 5 x 2 = 10 (สูง)"
      - "L = 5 = ความถี่จะเกิดข้อผิดพลาดในการปฏิบัติงาน (เฉลี่ย : ปี/ครั้ง) = 1 เดือนต่อครั้งหรือมากกว่าต่อเดือน"
      - "I = 2 = หยุดให้บริการ = ½ - 1 วัน"
- จากนั้นกด "Next >" ไปขั้น "ความเสี่ยงที่เหลืออยู่" (รายละเอียดอยู่หน้า 9 นอกช่วงของ spec นี้)

### กฎการคำนวณ (หน้า 8)
- **ระดับความเสี่ยง = L × I**
  - L = โอกาส 1–5
  - I = ผลกระทบ 1–5
  - ผลลัพธ์อยู่ในช่วง 1–25
- ค่า L และ I มาจาก dropdown คู่ (ประเด็น → ระดับ) ซึ่งเป็นเกณฑ์ที่ตั้งไว้ล่วงหน้า แต่ละตัวเลือกผูกกับคะแนน 1–5
  - ป้ายคะแนนที่เห็น: 5 = "สูงมาก", 2 = "น้อย"
  - ป้ายของคะแนนอื่นไม่เห็น (ไม่ชัด)
- Matrix 5×5
  - แกนตั้ง "ผลกระทบ (Impact/Consequences)" 1–5 จากล่างขึ้นบน
  - แกนนอน "โอกาส (Likelihood/Frequency)" 1–5
  - แถวบนสุด (I=5): 5, 10, 15, 20, 25
  - แถว I=4: 4, 8, 12, 16, 20
  - แถว I=3: 3, 6, 9, 12, 15
  - แถว I=2: 2, 4, 6, 8, 10
  - แถว I=1: 1, 2, 3, 4, 5
- ระดับและสี
  - ตัวอย่างเดียวที่ระบุชัดคือ 10 = "สูง" สีส้ม
  - ช่องที่ไม่ได้ถูกเลือกในภาพเป็นสีเทาทั้งหมด จึงอ่านช่วงคะแนนของแต่ละระดับจากหน้านี้ไม่ได้ (ไม่ชัด)
  - กราฟหน้าแรกใช้ 4 สี แดง/ส้ม/เหลือง/เขียว จึงน่าจะมี 4 ระดับ คือ สูงมาก/สูง/ปานกลาง/ต่ำ ข้อนี้เป็นการอนุมาน

### ความเชื่อมโยงกับเมนูอื่น
- ERM2 ดึงความเสี่ยงจาก ERM1 ตามปีงบประมาณและหน่วยงาน
- ส่วน ERM3 อยู่ในเมนู "ERM2 - 3" เดียวกัน (สารบัญหน้า 10)
- จาก text dump ส่วนที่อยู่นอกช่วงหน้าของ spec นี้มีคำว่า ตัวชี้วัด, เกณฑ์ตัวชี้วัด, "ระดับความเสี่ยงที่คาดหวังตามมาตรการ" ให้ดูใน spec ของหน้าถัดไป
