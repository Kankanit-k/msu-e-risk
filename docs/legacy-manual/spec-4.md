# Spec ส่วนที่ 4 — สไลด์ p31–p40 (คู่มือ "หน้า 29–38")

> หมายเหตุเลขหน้า: ไฟล์ pNN คือสไลด์ Canva ที่ NN; เลขหน้าที่พิมพ์ในคู่มือ = NN − 2 (p31 = "หน้า 29", p40 = "หน้า 38")
> ภาพหน้าจอในคู่มือมีขนาดเล็กมาก ตัวหนังสือในภาพหลายส่วนอ่านไม่ได้ — ระบุ "ไม่ชัด" ไว้; ข้อความบรรยายของคู่มือยืนยันกับ text.txt แล้ว
> ไม่มีการระบุบทบาทผู้ใช้ (role) ในหน้าเหล่านี้ — ใช้คำว่า "ผู้ใช้งาน" ทั่วไป และเลือก "คณะ/หน่วยงาน" เอง

## ควบคุมภายใน › ปค. 4 (ต่อจากสไลด์ p30 — "เมนูที่ 3: ปค. 4" เริ่มที่ text.txt บรรทัด ~2033)

หน้า p31 ("หน้า 29") เป็นส่วนท้ายของฟอร์มรายงานผลการดำเนินการของ ปค. 4

- หลังกรอก "รายงานผลการดำเนินการ" เสร็จ ให้เลื่อนลงไปช่องสุดท้าย แล้วกรอก
  1. "วันที่ดำเนินการ": date picker (ปฏิทินแสดงเดือน/ปี พ.ศ. เช่น "กุมภาพันธ์ 2568", รูปแบบ placeholder "DD MMMM YYYY")
  2. "เจ้าหน้าที่รับผิดชอบ": autocomplete/combobox — พิมพ์ค้นหาจาก "ชื่อ" หรือ "นามสกุล" ระบบแสดงรายชื่อบุคลากรให้เลือก (ตัวอย่างในภาพ พิมพ์ "สุระขั" → "นายอนุรักษ์ สุระขันตี")
- ปุ่ม "บันทึก" (สีน้ำเงิน มีไอคอนแผ่นดิสก์) อยู่ในแถวเดียวกับสองช่องนี้ → บันทึกข้อมูล
- required: คู่มือไม่ระบุ

## ควบคุมภายใน › ภาคผนวก ข. ("เมนูที่ 4: ภาคผนวก ข") — p32–p35 (หน้า 30–33)

**วัตถุประสงค์:** บันทึกผลการประเมินองค์ประกอบการควบคุมภายในของคณะ/หน่วยงาน ตามชุดข้อคำถาม (หัวหน้าจอในภาพประมาณว่า "ภาคผนวก ข. : รายงานผลการประเมินองค์ประกอบของการควบคุมภายใน คณะ/หน่วยงาน" — ตัวเล็ก ไม่ชัดทั้งหมด)

### ส่วนค้นหา (p32)
| ช่อง | ชนิด | หมายเหตุ |
| :-- | :-- | :-- |
| "ปีงบประมาณ" | dropdown (ล้างค่าได้ด้วย ×) | ตัวเลือกในภาพ: 2565, 2566, 2567, 2568, 2569, 2570, 2571 |
| "คณะ/หน่วยงาน" | dropdown/autocomplete | รายชื่อคณะ/หน่วยงานของ มมส (เช่น มหาวิทยาลัยมหาสารคาม, คณะ…) ตัวอักษรเล็ก ไม่ชัด |
| ปุ่ม "ค้นหา" | button (ไอคอนแว่นขยาย) | โหลดชุดข้อคำถาม |
| "ชุดข้อคำถาม" | dropdown (แสดงหลังค้นหา, label สีแดง) | ตัวเลือกในภาพ: "ชุดที่ 1 …" ถึง "ชุดที่ 5 …", ตามด้วย "5.1 แบบสอบถามการควบคุมภายใน ด้านการเงินและงบประมาณ", "5.2 …", "5.3 …", "5.4 …" (ชื่อเต็มชุดอื่น ไม่ชัด) |

- กฎ: ชุดข้อคำถามดึงมาจาก **เมนู "ตั้งค่าข้อคำถาม"** ของแต่ละคณะ โดยมี "ชุดข้อคำถามของส่วนกลาง 5 ชุดข้อคำถาม" เสมอ
- ก่อนค้นหา ตารางแสดง "- ไม่มีข้อมูล -" (empty state)
- เมื่อเลือกชุดข้อคำถามมีปุ่มสีเขียวข้าง dropdown (ข้อความ ไม่ชัด — น่าจะเป็นส่งออก/Export)

### ตารางข้อคำถาม (p33)
- คอลัมน์: "ข้อคำถาม" | คอลัมน์ปุ่มดำเนินการ (หัวคอลัมน์ ไม่ชัด)
- มีแถวหัวกลุ่มแถบสีเหลือง/ส้ม (ชื่อองค์ประกอบ เช่น "สภาพแวดล้อมการควบคุม" — ไม่ชัด) แล้วตามด้วยข้อคำถามลำดับ 1, 2, …
- ปุ่มต่อแถว:
  1. "เพิ่มรายงาน" (แดง) → เปิดหน้าต่างบันทึกรายงาน; เมื่อรายงานแล้วเปลี่ยนเป็น "แก้ไขรายงาน" (เขียว)
  2. "แนบเอกสาร" (แดง) → เปิดหน้าต่างแนบไฟล์/ลิงก์; เมื่อแนบแล้วเปลี่ยนเป็นสีเขียว
  3. ไอคอนดูรายงานผล (ไอคอนรูปภาพเล็ก) → ดูรายงาน

### Dialog 1: รายงานผลการดำเนินการ (p33)
หัว dialog: "ข้อคำถาม ภาคผนวก ข : <ข้อความข้อคำถาม>" (ข้อความข้อคำถามสีแดงเอียง)
| ช่อง | ชนิด | ตัวเลือก |
| :-- | :-- | :-- |
| "คำอธิบาย/คำตอบ" | rich text editor (B/I/U, list, align) | — |
| "การควบคุม" | radio | "N-A" / "มี - ใช่" / "ไม่มี - ไม่ใช่" |
| "ส่งข้อคำถามไป ปค. 5" | checkbox | ติ๊กเมื่อต้องการส่งข้อคำถามนี้ไปยัง ปค. 5 |
- ปุ่ม "บันทึก" → ปุ่มในแถวเปลี่ยนจาก "เพิ่มรายงาน" (แดง) เป็น "แก้ไขรายงาน" (เขียว)
- required: คู่มือไม่ระบุ

### Dialog 2: แนบเอกสาร (p34)
หัว: "ข้อคำถาม ภาคผนวก ข : <ข้อคำถาม>" ตัวอย่าง "1. มีกลไก และการกำกับ ติดตาม ให้การรับนิสิตเป็นไปตามแผนการรับ" (อ่านจากภาพ ค่อนข้างชัด)
- ซ้าย:
  - "เพิ่มลิงก์ไฟล์ (สามารถเพิ่มได้หลายลิงก์)" + ปุ่ม "เพิ่มลิงก์" (เพิ่มช่องลิงก์ได้หลายช่อง)
  - "เลือกไฟล์แนบ:" — dropzone "Drag & drop some files here, or click to select files"; หมายเหตุ: เลือกได้มากกว่า 1 ไฟล์ ชนิด *.jpeg, *.jpg, *.png, *.gif, *.pdf, *.csv, *.docx, *.doc, *.xlsx, *.xls, *.pptx, *.ppt; **ขนาดไฟล์รวมไม่เกิน 15 MB ต่อการบันทึก 1 ครั้ง**
  - ปุ่ม "บันทึกไฟล์" → บันทึกลิงก์และไฟล์พร้อมกัน; รายการที่บันทึกแล้วแสดงด้านขวา
- ขวา:
  - "หมายเหตุการใช้เอกสารร่วม:" text + ปุ่ม "บันทึก" — ใช้ระบุว่าใช้เอกสารร่วมกับข้อคำถามภาคผนวก ข ข้อที่…
  - ถ้ายังไม่มีไฟล์ แสดง "- ไม่มีเอกสารแนบ -" (สีแดง)

### สรุปผลการดำเนินงานต่อชุด (p35)
- ท้ายรายการข้อคำถาม มีช่อง "สรุปผลการดำเนินงาน…" (rich text; หัวข้อในภาพตัวเล็ก ไม่ชัดทั้งหมด) ของแต่ละชุดข้อคำถาม
- ปุ่ม "เพิ่มรายงานสรุปผลการดำเนินงาน" (แดง) → กดแล้วเปลี่ยนเป็นสีเขียวทันที
- ช่องสุดท้าย: "วันที่ดำเนินการ" (date, DD MMMM YYYY, ปฏิทิน พ.ศ.) + "เจ้าหน้าที่รับผิดชอบ" (autocomplete ค้นจากชื่อ/นามสกุล) + ปุ่ม "บันทึก" — เหมือนของ ปค. 4

**ลิงก์ไปเมนูอื่น:** ข้อที่ติ๊ก "ส่งข้อคำถามไป ปค. 5" จะไปปรากฏในเมนู ปค. 5

## ควบคุมภายใน › ปค. 5 ("เมนูที่ 5: ปค. 5") — p36–p37 (หน้า 34–35)

หัวหน้าจอในภาพประมาณ "ปค. 5 : รายงานการประเมินผลการควบคุมภายใน" (ไม่ชัดทั้งหมด)

### ส่วนค้นหา (p36)
- "ปีงบประมาณ": dropdown (2565–2571)
- "คณะ/หน่วยงาน": dropdown
- ปุ่ม "ค้นหา" → แสดงข้อคำถามจากภาคผนวก ข. ที่เลือกสถานะ "ส่งมา ปค.5" มารวมกัน
- หลังค้นหา มีปุ่มสีเขียวอีกปุ่ม (ข้อความ ไม่ชัด — น่าจะ Export)
- ตาราง คอลัมน์ (อ่านได้บางส่วน): [วัตถุประสงค์ของภารกิจ / ความเสี่ยง …] | "ผู้รับผิดชอบ / กำหนดเสร็จ" (ไม่ชัด) | "ตัวเลือก" (ไม่ชัด)

### กรณีไม่มีข้อมูล
- ตารางแสดงข้อความประมาณ "- คลิกปุ่มด้านขวา เพื่อยืนยันไม่มีข้อมูล ปค.5 -" (ไม่ชัดบางคำ)
- ปุ่ม "คลิกเพื่อยืนยัน ไม่มี ปค.5" (แดง) → กดยืนยันแล้วเปลี่ยนเป็นปุ่มเขียว "ยืนยันไม่มีข้อมูล ปค.5 แล้ว" (อ่านจากภาพ ค่อนข้างชัด)

### กรณีมีข้อมูล (p37)
- แต่ละแถวแสดง: "วัตถุประสงค์ของภารกิจ" + ข้อคำถาม (เช่น "11. …" — ไม่ชัด), "ความเสี่ยง" (เช่น "5.2 แบบสอบถามการควบคุมภายใน …" — ไม่ชัด), คอลัมน์ "ผู้รับผิดชอบ" / "กำหนดเสร็จ", คอลัมน์ปุ่ม
- ปุ่มต่อแถว:
  1. "เพิ่มรายงานผลการดำเนินการ" (แดง, ไอคอน +) → เมื่อรายงานแล้วเป็น "แก้ไขรายงานผลการดำเนินการ" (เขียว, ไอคอนดินสอ)
  2. ไอคอนดูรายงานผล

### Dialog รายงานผลการดำเนินการ (p37)
หัว: "ข้อคำถาม ปค.5 : <ข้อคำถาม>" (ไม่ชัดบางส่วน), มีปุ่มปิด ×
ฟิลด์ที่ต้องกรอก (ตามคู่มือ):
1. "วัตถุประสงค์ของภารกิจ" — rich text
2. "ความเสี่ยง" — rich text
3. "การควบคุมภายในที่มีอยู่" — (ชนิด ไม่ชัด, น่าจะ rich text)
4. "ความเสี่ยงที่ยังคงอยู่"
5. "การปรับปรุงการควบคุมภายใน"
6. "การประเมินผลการควบคุมภายใน" — radio 2 ตัวเลือก (ข้อความในภาพ ไม่ชัด; จากเมนูแบบติดตาม ปค.5 มีค่า "ไม่เพียงพอ" ⇒ น่าจะ "เพียงพอ" / "ไม่เพียงพอ")
7. "ผู้รับผิดชอบ" — dropdown/autocomplete
8. "หน่วยงานที่รับผิดชอบ" — dropdown
9. "วันที่กำหนดเสร็จ" — date
- ภาพแสดงซ้าย 2 ช่อง rich text, ขวาเป็น radio + dropdown 2 ช่อง + date (ฟิลด์ 3–5 ไม่เห็นในภาพ อาจอยู่ด้านล่าง — ไม่ชัด)
- ปุ่ม "บันทึก" → ปุ่มแถวเปลี่ยน แดง → เขียว ("แก้ไขรายงาน")
- ไม่มีปุ่มแนบเอกสารในเมนูนี้ (ตามภาพ/คู่มือ)

**ลิงก์:** รับข้อมูลจากภาคผนวก ข. (ข้อที่ติ๊ก "ส่งข้อคำถามไป ปค. 5"); ข้อที่ประเมินผล "ไม่เพียงพอ" จะไปอยู่ใน "แบบติดตาม ปค. 5"

## ควบคุมภายใน › แบบติดตาม ปค. 5 ("เมนูที่ 6: แบบติดตาม ปค. 5") — p38–p40 (หน้า 36–38)

หัวหน้าจอในภาพประมาณ "แบบติดตาม ปค. 5 : รายงานการประเมินผลการควบคุมภายใน" (ไม่ชัดบางส่วน)

### ส่วนค้นหา (p38)
- "ปีงบประมาณ": dropdown (2565–2571)
- "คณะ/หน่วยงาน": dropdown
- "รอบที่รายงาน": dropdown — 3 รอบ: 6 / 9 / 12 เดือน (ตัวเลือกในภาพ "รอบ 6 เดือน", "รอบ 9 เดือน", "รอบ 12 เดือน")
- ปุ่ม "ค้นหา" → แสดงข้อคำถามจาก ปค.5 ที่สถานะ "การประเมินผลการควบคุมภายใน" = "ไม่เพียงพอ"
- ปุ่มเขียวเพิ่มเติม (ข้อความ ไม่ชัด — น่าจะ "Export Word"/Export)
- ตาราง คอลัมน์ (อ่านได้บางส่วน): [การควบคุมภายในที่มีอยู่/ความเสี่ยง …] | "ความเสี่ยงที่มีอยู่" (ไม่ชัด) | "ผู้รับผิดชอบ/สถานะ/การควบคุม" (ไม่ชัด) | "ตัวเลือก"

- ข้อความในตารางประมาณ "- คลิกปุ่มด้านขวา เพื่อยืนยันไม่มีข้อมูล แบบติดตาม ปค.5 -"

- การยืนยันนี้แยกตามรอบ (6/9/12 เดือน) — อนุมานจากภาพ

### กรณีมีข้อมูล (p39)

## Status flow ร่วม (ภาคผนวก ข. / ปค. 5 / แบบติดตาม ปค. 5)
- ปุ่มรายงาน: แดง "เพิ่มรายงาน…" = ยังไม่รายงาน → เขียว "แก้ไขรายงาน…" = รายงานแล้ว
- ปุ่มแนบเอกสาร: แดง = ยังไม่มีเอกสาร → เขียว = มีเอกสารแล้ว
- ปุ่มยืนยันไม่มีข้อมูล (ปค.5 / แบบติดตาม): แดง "คลิกเพื่อยืนยัน ไม่มี …" → เขียว "ยืนยันไม่มีข้อมูล … แล้ว"
- Flow ข้อมูล: ตั้งค่าข้อคำถาม → ภาคผนวก ข. (ติ๊ก "ส่งข้อคำถามไป ปค. 5") → ปค. 5 (ประเมิน "ไม่เพียงพอ") → แบบติดตาม ปค. 5 (รอบ 6/9/12 เดือน)
- ไม่มีขั้นตอนอนุมัติ/approval ในหน้าเหล่านี้; ไม่มีสูตรคำนวณคะแนน
- เมนู "เอกสารเพื่อประเมินเบื้องต้น" และ "ตั้งค่าระบบ › เปิด-ปิด ระบบ" ไม่อยู่ในหน้า p31–p40 (คู่มือจบที่ p40)
